== Description ==

Cptkz Line Message is a simple and flexible plugin for managing line message on your WordPress site. Perfect for businesses that need to handle line message.

== Installation ==

1. Upload the 'cptkz-line-message' folder to the '/wp-content/plugins/' directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Configure your line message settings in the admin panel.
4. Use the provided shortcode [cptkz_line_message] to display the line message on any page.

== Frequently Asked Questions ==

= How do I display the line message? =
Use the shortcode [cptkz_line_message] on any page or post.
